# 2026-10-23 — 廠商月份訂單載入變慢
- Repository、分支、PR：`henryfir456/bento-order-app`、`perf/vendor-month-batching`；PR 與 head SHA 以 PR 頁面為準。
- 本輪目標：使用者回報廠商「訂餐」月曆載入特別久，要釐清原因。
- 根因（已驗證）：`/api/vendor/orders` 對當月每一天依序查 D1：店家模式、訂單明細、品名解析、是否歷史日、截止快照、轉帳，一天約 5～8 次，全部一個接一個。匯入過往訂單後，一個月約有 20 天，總共約 170 次依序查詢；正式環境每次約 0.1 秒，所以要十秒以上。店家頁和月曆用的是同一支 API。
- 實際修改：訂單明細、店家模式一次查整個月；品名解析先批次預取；各天的快照與轉帳查詢改成同時進行。回傳內容不變。
- 交付狀態：PARTIAL；待部署 Worker 後由使用者確認速度。
