# UI 文案與元件規範

給之後新增或修改畫面時使用。目的是讓員工、Admin、廠商三種畫面的用語與操作方式一致。

## 共用元件（src/components/ui/）
- `PageHeader`：頁面標題、一行說明、選用的「← 返回」連結。每個子頁都用它，返回連結寫「← 上一層名稱」。
- `LoadingNote`：載入中提示，文案固定為「〇〇載入中…」（使用刪節號「…」，不用三個點）。
- `ErrorNotice`：錯誤提示，一句人話 + 「重試」按鈕；錯誤碼與追蹤碼放進 `detail`（預設收合）。

## 文案
- 空狀態：「尚無〇〇」，若使用者可以做下一步，補一句指引，例如「到「訂餐」選擇開團日期即可下單。」
- 錯誤：「〇〇載入失敗，請重試」；不要把錯誤碼放在主要句子裡。
- 重試按鈕一律叫「重試」；資料頁頂部的手動「重新整理」只在確實需要時保留。
- 底部導覽名稱不得重複；員工是「我的足跡」，廠商是「售出足跡」。
- 管理中心入口名稱盡量不超過 6 個字，常用的放前面。

## 按鈕層級
- 主要：實心深綠（`bg-[#2C4A3E] text-white`），一個畫面一個。
- 次要：白底描邊（`border border-slate-300 bg-white`）。
- 危險：實心玫瑰紅（`bg-rose-700 text-white`），刪除或取消訂單等不可復原操作，且需經確認視窗（`Swal`，預設聚焦取消），不使用 `window.confirm`。
- 觸控目標至少 40px 高（數量加減鈕 40px，主要列表按鈕 44px）。

## 圖示
- 底部導覽使用線條 SVG。
- 標題與按鈕文字不加表情符號；表情符號只保留在狀態標籤（如「🟢 訂餐中」「🔒 已截止」），且必須同時有文字。
